## Task 1: Negative Elements in 1D Array
File: `task1.cpp`

Finds and displays all the negative elements from a given 1D array.

### Example
**Input:**
```text
Enter the array's size: 5
Enter array's elements:
a[0] = 2
a[1] = -4
a[2] = 1
a[3] = -3
a[4] = -5
```

**Output:**
```text
Negative elements from an Array: -4, -3, -5
```

## Task 2: Largest Element in 2D Array
File: `task2.cpp`

Traverses a 2D array and finds the maximum/largest element.

### Example
**Input:**
```text
Enter the array's row size: 3
Enter the array's column size: 3
Enter array's elements:
a[0][0] = 2
a[0][1] = 7
a[0][2] = 1
a[1][0] = 3
...
a[2][2] = 6
```

**Output:**
```text
The largest element is: 9
```

## Task 3: Transpose of 2D Array
File: `task3.cpp`

Computes and prints the transpose of a square matrix (2D array).

### Example
**Input:**
```text
Enter the array's row & column size: 3
Enter array's elements:
a[0][0] = 2
a[0][1] = 4
a[0][2] = 1
...
```

**Output:**
```text
The transpose matrix of an array:
2 3 8 
4 5 2 
1 4 6 
```

## Task 4: Sum of Row & Column Elements in 2D Array
File: `task4.cpp`

Allows the user to query a row or column of a 2D array, prints its elements, and calculates the sum.

### Example
**Input/Output:**
```text
Enter row number: 0
Elements of row 0: 2, 7, 1
The sum of a row 0: 10

Enter column number: 2
Elements of column 2: 1, 4, 6
The sum of column 2: 11
```
